# JMGO P5 Russian input suite

Набор исходников для русскоязычного интерфейса и ввода на проекторе JMGO P5.

## Состав

- `jmgo-input-modules/` — общий Android-модуль: маршрутизация микрофонной кнопки, безопасная работа с активным полем и web-клавиатура/курсор.
- `zagonka-tv-wrapper/` — TV-обёртка сайта «Загонка» на WebView. Использует общий web-модуль и небольшой адаптер сайта.
- `flauncher-jmgo/` — адаптированный FLauncher с системным мостом голосового ввода для нативных приложений.
- `futo-voice-jmgo/` — офлайн-распознавание русской речи. В JMGO-сборке собственная IME-поверхность отключена: нативные приложения сохраняют свою клавиатуру и интерфейс.

## Поведение

- На сайтах модуль показывает собственную TV-клавиатуру и курсор только по запросу пользователя.
- В нативных приложениях вроде VK Видео и SmartTube web-интерфейс не запускается.
- Кнопка микрофона вызывает русское распознавание, а результат вставляется только в активное редактируемое поле исходного окна.
- Поля пароля, выключенные и read-only поля игнорируются.
- Результаты распознавания привязаны к идентификатору сеанса и имеют тайм-аут.

## Активация на устройстве

После установки лаунчера сервис `Русский голосовой ввод` нужно один раз включить в системном разделе специальных возможностей Android. Он экспортирован только для системного подключения и защищён разрешением `BIND_ACCESSIBILITY_SERVICE`. Код намеренно не включает сервис сам и не меняет secure settings.

FUTO JMGO используется как отдельный офлайн-распознаватель. Его не нужно выбирать системной клавиатурой: в нативных приложениях остаются их штатные UI и ввод, а общий web-интерфейс загружается только приложениями, которые явно подключили `web-input`.

## Первоначальная настройка на проекторе

После установки APK лаунчер сам показывает экран «Голосовой ввод» (Настройки → Голосовой ввод), пока не выполнены все шаги:

1. установлена JMGO-сборка FUTO Voice Input (`org.futo.voiceinput.jmgo`);
2. FUTO выдано разрешение на микрофон;
3. в системном разделе «Специальные возможности» включён сервис «Русский голосовой ввод»;
4. «Русский лаунчер» выбран домашним экраном.

Каждый шаг показывает статус и кнопку перехода в нужный системный экран. Лаунчер ничего не включает сам и не меняет secure settings. Пока сервис выключен, кнопка микрофона на главном экране открывает этот же экран настройки вместо бесполезного запуска распознавания.

Внизу экрана — диагностика без записи речи и содержимого полей: подключён ли сервис, сколько событий клавиш прошло через него, когда последний раз пришла кнопка микрофона (в сервис и в лаунчер) и чем закончилась последняя сессия.

Порядок установки APK: FUTO → FLauncher → Zagonka. Удаление — в обратном порядке; перед удалением лаунчера выберите другой домашний экран и выключите сервис в «Специальных возможностях».

## Сборка и тесты

Нужен JDK 17. Android SDK задаётся локальным `local.properties`, который намеренно не хранится в Git.

```bash
# Общий модуль и Загонка
./flauncher-jmgo/android/gradlew -p zagonka-tv-wrapper \
  :input-core:test :web-input:test :app:testDebugUnitTest \
  :input-core:assemble :web-input:assemble :app:assembleDebug

# DOM-логика web-модуля
node --test jmgo-input-modules/web-input/src/test/js/jmgo-web-input.test.js

# Лаунчер
./flauncher-jmgo/android/gradlew -p flauncher-jmgo/android \
  app:testDebugUnitTest app:assembleDebug

# Голосовой сервис
./futo-voice-jmgo/gradlew -p futo-voice-jmgo \
  testPlayStoreDebugUnitTest assemblePlayStoreDebug
```

Все компоненты одной командой из корня (нужны JDK 17, Android SDK, Node.js и Flutter 3.7.5):

```bash
scripts/build-all.sh          # тесты и debug-сборки
scripts/build-all.sh --tests  # только тесты
```

GitHub Actions (`.github/workflows/ci.yml`) собирает и тестирует все компоненты на каждый push и pull request и публикует debug-APK как артефакты. Для FLauncher нужен секрет `GOOGLE_SERVICES_JSON` с содержимым `google-services.json`; без него CI подставляет заглушку из `.github/placeholders/`, и такой APK годится только как проверка сборки.

Состояние проекта, известные проблемы и план работ: `docs/status.md`.

Проекты FLauncher и FUTO Voice Input содержат собственные лицензии и сведения об исходных проектах. Секреты, подписи, локальные настройки, core-дампы и готовые APK в этот репозиторий не включены.
