# JMGO Vosk Recognition Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Return Russian voice-search text quickly on JMGO P5 with offline Vosk and retain Whisper as fallback.

**Architecture:** A pure selector limits Vosk to the `.jmgo` application ID and an installed model directory. A process-wide Vosk model transcribes the existing 16 kHz float buffer; `AudioRecognizer` falls back to its current Whisper path on any Vosk infrastructure failure.

**Tech Stack:** Kotlin, Android 13, Vosk Android 0.3.75, kotlinx.serialization, JUnit 4, Gradle.

**Spec:** `docs/superpowers/specs/2026-09-02-jmgo-vosk-design.md`

## Global Constraints

- Recognition remains offline.
- Only `org.futo.voiceinput.jmgo` uses Vosk.
- The existing `finished(String)` contract and Whisper behavior remain compatible.
- The target device ABI is `armeabi-v7a`.

### Task 2: Add the Vosk engine and AudioRecognizer fast path

**Files:**
- Modify: `app/build.gradle`
- Create: `app/src/main/java/org/futo/voiceinput/JmgoVoskEngine.kt`
- Modify: `app/src/main/java/org/futo/voiceinput/AudioRecognizer.kt`

**Interfaces:**
- Consumes: private directory `files/vosk-model-small-ru-0.22`.
- Produces: `JmgoVoskEngine.prepare(modelDirectory: File)` and `JmgoVoskEngine.transcribe(modelDirectory: File, samples: FloatArray): String`.

- [ ] **Step 1: Add the official Vosk dependency**

Add `implementation 'com.alphacephei:vosk-android:0.3.75'` next to the existing serialization dependency.

- [ ] **Step 2: Implement the process-wide engine**

Construct `org.vosk.Model` once for the directory path. In `transcribe`, create `Recognizer(model, 16000.0f)`, call `acceptWaveForm(samples, samples.size)`, parse `finalResult`, and close only the recognizer.

- [ ] **Step 3: Route JMGO recognition through Vosk**

During `loadModelInner`, call `prepare` when the policy selects Vosk. In `runModel`, join the preload, call Vosk, deliver the text through the existing main-thread callback, and return. Catch Vosk infrastructure errors and run the unchanged Whisper load/inference path.

- [ ] **Step 4: Run regression tests and build**

Run `./gradlew app:testPlayStoreDebugUnitTest app:assemblePlayStoreDebug` and require both tasks to succeed.
